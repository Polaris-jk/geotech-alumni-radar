# KKU Geotech Alumni Radar · เรดาร์ศิษย์เก่าเทคโนโลยีธรณี

แผนที่ศิษย์เก่าและนักศึกษา สาขาวิชาเทคโนโลยีธรณี คณะเทคโนโลยี มหาวิทยาลัยขอนแก่น

- ศิษย์เก่าปักหมุดที่ทำงานหรือที่เรียน แผนที่แสดงชื่อเล่น รุ่น G และสายงาน
- เลือกเปิดโอกาสให้รุ่นน้องได้ 3 แบบ แต่ละแบบมีช่องทางติดต่อของตัวเอง: รับสมัครงาน, รับฝึกงาน/สหกิจ, ยินดีเล่าประสบการณ์
- Batch Battle นับหมุดตามรุ่น G และบอกว่ารุ่นไหนยังไม่มีหมุด
- สลับภาษาไทย/อังกฤษ ใช้ได้ทั้งมือถือและคอม
- หลังบ้านคือ Google Sheet: ดู แก้ ซ่อน และลบหมุดได้จากชีต

## ไฟล์ในโปรเจกต์

```
index.html            หน้าเว็บ
config.js             ค่าที่ต้องแก้ (apiUrl, latestBatch, อีเมลสาขา)
assets/style.css      หน้าตาเว็บ
assets/app.js         การทำงานของหน้าเว็บ
data/basemap.js       ขอบเขตประเทศและจังหวัด
vendor/leaflet/       ไลบรารีแผนที่ Leaflet 1.9.4
apps-script/Code.gs   โค้ดหลังบ้านสำหรับ Google Sheets
```

ถ้า `apiUrl` ใน `config.js` ยังว่าง เว็บจะเป็นโหมดสาธิต แสดงศิษย์เก่าสมมติ และหมุดที่เพิ่มจะหายเมื่อรีเฟรช

## ขั้นที่ 1 · ตั้งหลังบ้านบน Google Sheets (ประมาณ 10 นาที ทำบนคอมจะง่ายกว่า)

1. สร้าง Google Sheet ใหม่ ควรใช้บัญชีกลางของสาขา ไม่ใช่บัญชีส่วนตัว ข้อมูลจะได้ไม่หายเมื่อคนดูแลเปลี่ยน
2. ในชีต ไปที่เมนู **Extensions → Apps Script** ลบโค้ดเดิมทิ้ง วางโค้ดทั้งหมดจาก `apps-script/Code.gs` แล้วกด Save
3. เลือกฟังก์ชัน `setup` ที่แถบด้านบน แล้วกด **Run** และกดอนุญาตสิทธิ์
   - Google จะเตือนว่าแอปยังไม่ผ่านการยืนยัน เพราะเป็นสคริปต์ที่เราเขียนเอง ให้กด Advanced แล้วกด Go to … (unsafe)
4. กด **Deploy → New deployment** เลือกประเภท **Web app** แล้วตั้งค่า
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
5. กลับไปที่ชีตแล้วรีเฟรช จะเห็นแท็บ `pins` และเมนู **Geotech Radar**

## ขั้นที่ 2 · ใส่ URL ใน config.js

เปิดไฟล์ `config.js` บน GitHub กดรูปดินสอ (Edit) วาง URL ที่คัดลอกมาใน `apiUrl` แล้วกด **Commit changes**

```js
apiUrl: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

ใส่ `branchEmail` ด้วย เพื่อให้ศิษย์เก่ารู้ว่าต้องติดต่อใครเมื่อต้องการแก้ไขหรือลบหมุด

## ขั้นที่ 3 · เปิดเว็บด้วย GitHub Pages

1. ใน repo ไปที่ **Settings → Pages**
2. Build and deployment → Source: **Deploy from a branch**
3. Branch: **main** และโฟลเดอร์ **/ (root)** แล้วกด Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://polaris-jk.github.io/geotech-alumni-radar/`

## หลังบ้าน: ดู แก้ไข ซ่อน ลบ

เปิด Google Sheet แท็บ `pins` โดย 1 แถวคือ 1 หมุด

| ต้องการ | ทำอย่างไร |
|---|---|
| ซ่อนหมุดออกจากแผนที่ | เปลี่ยนช่อง `status` เป็น `hide` หรือเลือกแถว แล้วกดเมนู Geotech Radar → ซ่อนหมุดในแถวที่เลือก |
| เอาหมุดกลับมา | เปลี่ยน `status` เป็น `show` |
| แก้ข้อมูล | แก้ในช่องได้เลย เช่น ชื่อสะกดผิด หรือพิกัด `lat`/`lon` |
| ลบถาวร | ลบทั้งแถว เช่น เมื่อเจ้าของขอลบข้อมูล |
| ให้เว็บเห็นการแก้ไขทันที | เมนู Geotech Radar → อัปเดตแผนที่ทันที (ถ้าไม่กด เว็บจะอัปเดตเองภายในประมาณ 1 นาที) |

- หมุดใหม่ขึ้นแผนที่ทันทีที่ส่ง แอดมินจึงควรเปิดดูชีตเป็นประจำ
- `full_name` และ `consent_at` เป็นข้อมูลส่วนตัว ไม่ถูกส่งไปที่หน้าเว็บ
- แชร์ชีตให้ทีมแอดมินแบบ Editor เป็นรายคน ห้ามตั้งเป็น "Anyone with the link"
- สำรองข้อมูลเป็นระยะ: File → Download → Microsoft Excel หรือ CSV

ความหมายของรหัสในชีต

- `batch` เลขรุ่น G (0 = ไม่มีรุ่น G เรียนเฉพาะ ป.โท/ป.เอก)
- `level`: `cur` นักศึกษาปัจจุบัน, `bsc` `msc` `phd` ศิษย์เก่า ป.ตรี ป.โท ป.เอก
- `career`: `eng` ธรณีเทคนิค, `gw` น้ำบาดาล, `env` สิ่งแวดล้อมและภัยพิบัติ, `min` แร่ เหมือง ปิโตรเลียม, `geo` ธรณีฟิสิกส์ สำรวจ ภูมิสารสนเทศ, `gov` ราชการ, `biz` ที่ปรึกษา ก่อสร้าง ธุรกิจ, `res` วิจัย ศึกษาต่อ, `oth` อื่นๆ
- `place`: `th:40` คือรหัสจังหวัด (40 = ขอนแก่น), `ab:sin` คือเมืองต่างประเทศ
- `share_topics`: `study` การเรียน, `intern` ฝึกงาน, `work` การทำงาน

## เมื่อแก้โค้ด

- แก้ `Code.gs` แล้ว ต้องกด **Deploy → Manage deployments → ดินสอ → Version: New version → Deploy** URL เดิมใช้ต่อได้
- แก้ `assets/style.css` หรือ `assets/app.js` แล้ว ให้เปลี่ยน `?v=1` เป็น `?v=2` ใน `index.html` เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
- ขึ้นปีการศึกษาใหม่ เพิ่ม `latestBatch` ใน `config.js` ทีละ 1

## ข้อควรรู้

- repo นี้เป็น public ห้ามใส่ข้อมูลส่วนตัว รหัสผ่าน หรือไฟล์ที่ export จากชีตลงใน repo
- กันสแปมไว้ 3 ชั้น: ช่องซ่อนที่มีแต่บอทกรอก, จำกัด 30 หมุดต่อ 10 นาที (`MAX_POSTS_PER_10_MIN` ใน Code.gs), และตรวจทุกช่องก่อนบันทึก
- ข้อความยินยอมในฟอร์มควรให้คณะตรวจตาม PDPA ก่อนเปิดใช้จริง
- แผนที่ละเอียด (มีถนน แม่น้ำ ภูมิประเทศ): ขอคีย์ฟรีที่ https://carto.com/basemaps/apikey แล้วใส่ใน `cartoKey` หน้าเว็บจะแสดงเครดิต OpenStreetMap และ CARTO ให้เอง
- ทดลองในเครื่อง: เปิด `index.html` ได้เลย
